**Line-by-Line Explanation, Exam Style**

Lines `1-5`: Include required libraries.  
`stdio.h` for `printf`, `stdlib.h` for `malloc/free`, `time.h` for timing/random seed, `cuda_runtime.h` for CUDA functions, `stdbool.h` for `bool`.

Lines `7-15`: `CUDA_CHECK` macro checks CUDA API errors like `cudaMalloc`, `cudaMemcpy`, and kernel launch errors.

Lines `17-23`: GPU kernel for vector addition. Each GPU thread calculates one index `tid` and performs:

```c
c[tid] = a[tid] + b[tid];
```

Lines `25-29`: CPU version of vector addition using a normal `for` loop.

Lines `31-38`: Compares GPU and CPU vector outputs.

Lines `40-54`: GPU kernel for matrix multiplication. Each thread computes one element of result matrix `C`.

Lines `42-43`: Calculate row and column handled by current GPU thread.

Lines `48-50`: Dot product logic:

```c
C[row][col] = sum of A[row][k] * B[k][col]
```

Lines `56-69`: CPU version of matrix multiplication using three nested loops.

Lines `71-78`: Compares GPU and CPU matrix outputs.

Lines `80-140`: Complete vector addition practical:
allocates CPU memory, fills random values, allocates GPU memory, copies data to GPU, launches kernel, copies result back, runs CPU version, verifies result, prints time and speedup, frees memory.

Lines `142-216`: Complete matrix multiplication practical:
sets matrix sizes, checks valid multiplication condition, allocates memory, fills random values, copies matrices to GPU, launches CUDA kernel, copies result back, runs CPU multiplication, verifies result, prints timing and speedup, frees memory.

Lines `218-246`: Main menu. Takes user choice and calls vector addition, matrix multiplication, or both.

**What To Say In Viva**

This program demonstrates parallel computation using CUDA. In CPU execution, operations run sequentially using loops. In GPU execution, many threads run in parallel. For vector addition, each thread computes one vector element. For matrix multiplication, each thread computes one output matrix element. Finally, CPU and GPU results are compared to verify correctness, and speedup is calculated as:

```c
speedup = CPU time / GPU time
```

**Common Exam-Friendly Answer**

If examiner asks why `nvcc` error comes:
